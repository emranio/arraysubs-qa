# Pro email audit — task 91

Source inspection covers both plugins' ownership boundaries and the Pro email extensions listed below. Runtime checks use actual local WordPress/WooCommerce with disposable fixtures and intercepted transport. They do not establish actual SMTP delivery, full lifecycle coverage, or complete browser coverage. Parent task 91 owns the real browser preview checks and broad core/Pro render suite.

## Confirmed defects and source changes

- Issue 93, commits `78a25bc` and `8d6600e`, branch `codex/credit-email-notifications`: four StoreCredit email constructors listened on raw actions even though `Services/EmailManager.php:63–77` registers those events with Woo's transactional dispatcher. Woo emits the `_notification` event after lazy initialization or queue delivery (`woocommerce/includes/class-wc-emails.php:175–224`). Constructors now use that event. The source registration remains module/provider owned.
- All four Pro plain templates HTML-escaped customer names/currency and emitted HTML footer markup. `get_content_plain()` now uses the shared core `arraysubs_format_plain_email_content()` helper. HTML escaping remains intact.
- Zero-context previews ignored their own sample placeholders and rendered zero amounts. Preview template arguments now use coherent sample data only when `customer_id === 0`; real zero amounts remain zero. The sample used-order link opens Woo's Orders list, while real emails retain their actual order detail URL.
- Subscription/order/ledger currency was discarded by all four email classes. A GBP subscription under a USD store rendered dollar amounts, and CreditUsed summed customer USD credit with subscription GBP credit. Source currency now reaches placeholders and both template formats; the remaining balance includes only applicable same-owner/same-currency buckets. Expired consumes the existing emitted log/subscription arguments.

## Other inspected boundaries

- `arraysubspro/src/Features/StoreCredit/Provider.php:24–57` and core `Supports/Abstracts/AbstractLoader.php:34–86`: EmailManager is not a `runsWhenModuleDisabled` service, so credit email registration stays off when the module is unavailable. Core does not depend on the Pro credit email classes. A queued Woo event without the Pro provider has no Pro notification listener.
- `StoreCredit/Services/CreditExpiration.php:71–79,267–287`: module-off jobs return; expiring notification releases its marker when disabled. Email handling reads existing expiry data without exposing customer APIs or internal feature metadata.
- `CartInfoEditor/Services/Hooks.php:115–175,322–454`: email-only guard, product-item and renewal checks, non-array/invalid-row guards, escaped labels, `wp_kses_post` values, and decoded literal plain text. No internal feature types/configuration are rendered. Core `SubscriptionProducts/Services/Hooks.php:1396–1425` owns capture of the frozen subscription display rows; Pro CartInfoEditor owns their additional Woo order-email rendering. This ownership observation is not classified as a missing-Free defect because the enhancement's product entitlement was not independently established.
- `SubscriptionBundle/Services/OrderHooks.php:545–555`: bundle-child name decoration uses a plain arrow prefix, avoiding HTML in plain email contexts and handling non-product items defensively.
- `CancellationFlow/Services/Hooks.php:55–68` and `SubscriptionShipping/REST/ShippingController.php:197`: emit extension actions; no additional Pro email class or unguarded Free caller was found. Core owns subscription lifecycle/retention email classes.
- Across the four credit HTML templates: names/source/date/order labels are escaped, amounts and additional content use allowed HTML, URLs use Woo page/endpoint helpers, and missing customer lookup falls back safely for rendering. Triggers skip missing customer recipients. No feature type labels, type classes, raw feature configuration, or premium-only REST fetch occurs in these email paths.

Source review found no further independent missing-Pro endpoint or email-render dependency in the checked Pro surfaces. This is a scoped audit, not a claim that every email, third-party override, locale, or delivery worker has been exercised.
